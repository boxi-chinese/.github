# Boxi Chinese community health files

Boxi Chinese builds open, inspectable resources for learning and using Mandarin Chinese.

The organization separates reusable learning code, public scenarios, public documentation, and private learner or course records. Contributions should state the learning objective, context, source provenance, feedback method, accessibility path, and content license.

Public repositories:

- [`chinese-explain`](https://github.com/boxi-chinese/chinese-explain) — learning primitives and lesson contract
- [`chinese-scenarios`](https://github.com/boxi-chinese/chinese-scenarios) — reproducible scenarios and practice fixtures
- [`chinese-site`](https://github.com/boxi-chinese/chinese-site) — public documentation and demos
