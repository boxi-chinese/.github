# Contributing to Boxi Chinese

Start with an issue that states the learner need. New scenarios must include context, Chinese text, pinyin/tone information where relevant, a learner task, an inspectable feedback rubric, a revision path, an accessible text alternative, and a license/source record.

Do not submit personal learner records, secrets, scraped copyrighted media, or unsupported proficiency claims. Prefer small pull requests with reproducible fixtures and clear licensing.
